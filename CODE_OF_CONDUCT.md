# Code of Conduct

LitOpenCode welcomes participants across backgrounds and levels of experience.
This code applies to project issues, pull requests, reviews, and other spaces
maintained for the project.

Discuss ideas and behavior respectfully. Make technical criticism specific and
actionable, respect differing experience, and credit others' work. Ask before
sharing another person's private information. Accept a maintainer's request to
stop an unproductive or harmful exchange.

Harassment, discriminatory abuse, threats, sexual harassment, doxxing, and repeated
personal attacks are unacceptable. Do not use project spaces to target someone
elsewhere. Disagreement about a technical decision is welcome; intimidation is not.

Maintainers may edit or remove harmful content, lock a discussion, warn a
participant, or restrict participation according to the conduct and its impact.
They should explain the reason where doing so does not expose private information.
Reports and responses should disclose only what is needed to address the concern.

To report a concern, use an existing private maintainer contact if one has been
provided. This repository does not publish a dedicated conduct-reporting address.
Otherwise, ask for a private contact in a minimal issue without identifying affected
people or posting sensitive details. Do not use a public issue to disclose private
evidence. A maintainer involved in a report should defer its handling to another
available maintainer; where that is not possible, the limitation should be stated.

Participants may ask for a decision to be reconsidered with new context through
the same reporting channel. No response deadline or confidential service beyond
the actual reporting channel is promised.
