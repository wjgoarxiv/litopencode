# 적용 범위와 책임

이 절차서는 연구동 2층부터 5층까지 실험실 34곳에서 나오는 액상 화학 폐기물에 적용한다. 고상 폐기물, 감염성 폐기물, 방사성 물질은 각각 별도 절차서를 따른다. 위탁 연구원과 실습생도 예외가 아니다.

## 역할 구분

::: sidebar title="이 절차서의 용어" width=third float=right
**폐액 용기**: 환경안전팀이 지급한 20L 고밀도 폴리에틸렌 용기.

**분류 코드**: 용기 라벨에 적는 A부터 F까지의 성상 구분.

**보관소**: 연구동 지하 1층 B-104호, 환기 설비와 방류벽을 갖춘 임시 보관 시설.

**인계**: 실험실이 보관소 담당자에게 용기를 넘기고 대장에 서명하는 절차.
:::

실험실 책임자는 소속 실험실에서 나오는 폐액의 분류와 라벨 기재가 정확한지 확인한다. 실제 배출과 용기 관리는 폐액 담당자가 맡는다. 담당자는 실험실마다 1명을 지정하며, 휴가나 출장으로 2주 이상 자리를 비우거나 인사이동으로 바뀌는 경우에는 대리인 이름과 연락처를 3영업일 안에 환경안전팀 전산 게시판에 등록한다.

환경안전팀은 용기와 라벨을 공급하고, 매주 화요일과 금요일 오후에 층별 수거를 진행한다. 보관소 담당자는 인계받은 용기의 상태와 기재 내용을 대조하고, 보관 기간이 45일을 넘기 전에 위탁 처리 업체에 반출을 요청한다.

외부 위탁 처리 업체는 환경안전팀과 맺은 연 단위 계약에 따라 월 2회 이상 보관소를 방문해 폐액을 반출하며, 반출할 때마다 폐기물 인계서 사본과 함께 차량 번호, 운반자 이름, 반출 용기 수를 적은 확인서를 환경안전팀에 제출하고 원본은 3년 동안 보관한다. 계약은 매년 갱신한다.

# 폐액 분류와 용기

폐액은 혼합했을 때 반응할 수 있는 성분끼리 섞지 않는 것이 원칙이다. 분류가 애매하면 배출 전에 환경안전팀(내선 4120)에 문의하고, 확인 전까지는 원래 시약병에 따로 보관한다.

## 분류 코드

표 1. 폐액 분류 코드와 대표 성분

| 코드 | 구분 | 대표 성분 | 용기 색 띠 |
|---|---|---|---|
| A | 할로겐 유기용매 | 디클로로메탄, 클로로포름 | 녹색 |
| B | 비할로겐 유기용매 | 메탄올, 아세톤, 헥산 | 청색 |
| C | 산성 수용액 | 염산, 황산 희석액 (pH 2 이하) | 적색 |
| D | 염기성 수용액 | 수산화나트륨 희석액 (pH 12 이상) | 황색 |
| E | 중금속 함유 수용액 | 크롬, 납, 수은 화합물 | 흑색 |
| F | 산화성 물질 | 과산화수소 고농도, 질산염 | 백색 |

자료: 연구소 폐액 처리 지침 별표 1(예시)

주: pH 2 초과 12 미만의 일반 수용액은 실험실 중화 후 하수 배출 기준을 따른다.

## 용기 사용 기준

용기는 80% 이상 채우지 않는다. 20L 용기라면 눈금 16L 선이 상한이며, 넘친 경우에는 즉시 새 용기로 옮겨 담는다. 뚜껑은 배출할 때만 열고, 깔때기를 꽂아 둔 채 방치하지 않는다.

# 배출과 보관 절차

실험실 안에서 폐액을 모으는 단계와 보관소로 옮기는 단계를 구분한다. 두 단계 모두 실험복, 보안경, 내화학 장갑을 착용한 상태에서 진행한다.

## 실험실 내 배출

1. 배출할 폐액의 성분을 확인하고 표 1의 분류 코드를 정한다.
2. 같은 코드의 용기를 흄후드 안 또는 2차 용기 위에 놓는다.
3. 깔때기로 천천히 붓고, 배출 직후 깔때기를 빼고 뚜껑을 닫는다.
4. 라벨의 배출 기록란에 날짜, 성분, 대략의 양(mL), 배출자 이름을 적는다.
5. 용기가 16L 선에 도달하면 라벨의 마감란에 날짜를 적고 수거 대기 구역으로 옮긴다.

::: callout kind=warning title="혼합 금지 조합"
산화성 물질(F)과 유기용매(A, B)는 같은 용기에 넣지 않는다. 질산이 섞인 폐액에 아세톤이나 메탄올을 부으면 발열과 기체 발생이 일어나며, 뚜껑을 닫은 용기는 파열될 수 있다. 의심되는 혼합이 생기면 뚜껑을 닫지 말고 흄후드 안에 둔 채 환경안전팀에 즉시 연락한다.
:::

## 보관소 인계

1. 수거일 오전 11시까지 실험실 폐액 담당자가 전산 신청서를 제출한다.
2. 수거 담당자가 도착하면 라벨 기재 내용과 용기 외관을 함께 확인한다.
3. 누액, 변형, 라벨 누락이 있는 용기는 인계하지 않고 실험실에서 보완한다.
4. 인계 대장에 실험실 번호, 코드, 수량을 적고 양측이 서명한다.

## 보관소 관리

보관소 담당자는 코드별 선반에 용기를 나누어 놓고, A와 F는 서로 다른 벽면에 둔다. 매일 오전 9시에 환기 설비 작동 여부와 방류벽 안 누액을 점검하고 결과를 점검표에 기록한다.

표 2. 보관소 일일 점검 항목

| 항목 | 기준 | 미달 시 조치 |
|---|---|---|
| 환기 설비 | 배기 풍량 표시등 정상 | 시설팀 호출, 출입 제한 |
| 방류벽 | 고인 액체 없음 | 흡착포 처리 후 원인 용기 격리 |
| 보관 기간 | 입고 후 45일 이내 | 위탁 업체에 반출 요청 |
| 적재량 | 용기 120개 이하 | 추가 입고 중단 |
| 소화기 | 압력계 녹색 범위 | 교체 요청 |

자료: 폐액 보관소 운영 점검표 양식(2026년, 예시)

# 사고 발생 시 조치

소량 누출(1L 미만)은 실험실 비치 흡착포로 처리하고, 사용한 흡착포는 고상 폐기물 봉투에 넣어 라벨을 붙인다. 1L 이상 누출, 피부 접촉, 기체 흡입이 있으면 다음 순서를 따른다. 순서를 건너뛰지 않는다.

1. 주변 인원을 대피시키고 실험실 출입문을 닫는다.
2. 피부나 눈에 닿았으면 비상 샤워기나 세안기로 15분 이상 씻는다.
3. 환경안전팀 비상 번호(내선 4119)로 위치, 물질, 양을 알린다.
4. 환경안전팀 도착 전까지는 누출 물질을 직접 치우지 않는다.

경위서는 사고 처리 후 48시간 안에 실험실 책임자가 쓰며, 누출 물질과 양, 발견 시각, 초기 조치, 노출된 인원, 원인으로 추정되는 작업을 빠짐없이 적는다. 환경안전팀은 경위서를 바탕으로 원인을 분류하고, 같은 원인이 분기 2회 이상 반복되면 해당 실험실 전원을 대상으로 재교육을 실시한다.
