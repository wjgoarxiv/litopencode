UI/UX Pro Max design data

This package includes a normalized subset of design data from
nextlevelbuilder/ui-ux-pro-max-skill at Git commit
1307d97a72e6c1cda572cb65471ae5ce82995218.

The reused data is licensed under the MIT License. The full pinned license is
distributed beside this notice as LICENSE. PROVENANCE.json records all 34 allowlisted CSV source files
with their raw hashes, selected columns, row counts,
the deterministic repair receipt, and the canonical dataset hash.

No upstream scripts, templates, CLI, installers, manifests, screenshots, previews,
documentation, premium features, host integrations, code-example columns,
documentation-URL columns, or google-fonts.csv data are included.
