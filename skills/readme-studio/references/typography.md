# Real inputs and crisp type

Image-generation availability belongs to the active OpenCode session, not the model's description of itself. Check its tool list and capabilities. A real native generator result must be inspected, saved inside the authorized project, and recorded with prompt and provenance. Without a callable generator report IMAGE_GENERATION_UNAVAILABLE and finish independent README work. The supplied-background branch may then complete composition, but never becomes native-generation evidence. CSS atmospheres are effects, not generated backgrounds.

Use Pretendard for Korean/prose/display and Meslo LGS NF for technical labels. Resolve actual regular font files and readable licenses locally. Record family, style, version, SHA256 and license source before rendering. Do not install system fonts, silently substitute or redistribute uncertain font bytes. A source image must be inspected for words/logos and appropriate mobile/wide crops; preserve it unmodified.

From the exact selected SKILL.md root copy `templates/typography/` to a fresh project-local tools directory. Install there with `npm ci --ignore-scripts --no-audit --no-fund`; the lock pins fontkit 2.0.4 (MIT). With explicit existing project root and output parent directories:

```sh
node ./tools/typography/outline.mjs --font "./inputs/Pretendard-Regular.otf" --family Pretendard --license "./inputs/Pretendard-LICENSE.txt" --text "연구 노트" --root "$PWD" --output "assets/title-dark.svg" --fill '#15242a'
node ./tools/typography/outline.mjs --font "./inputs/MesloLGS NF Regular.ttf" --family 'MesloLGS NF' --license "./inputs/Meslo-LICENSE.txt" --text "FIELD NOTES / 01" --root "$PWD" --output "assets/label-light.svg" --fill '#f4f1e9'
```

The helper accepts bounded regular files, shapes glyph runs with positions and advances, checks all requested glyphs, and includes transformed outline bounds in its viewBox. Whitespace advances without visible outlines. Paths are escaped and output is exclusive; unsafe parent paths/symlinks and missing glyphs fail. Review the recorded license yourself: presence of license text is not legal verification. Stdout reports actual font identity/hash; save it in the asset manifest along with the editable source string. A paths-only SVG still needs text alternatives in Markdown.

Create title/subtitle/label variants for each ink palette. Dark-ink filenames bind to light fields; light-ink filenames bind to dark fields. External SVGs do not inherit CSS color. Inspect path fill and its solid backing field for >=4.5:1 contrast before rendering. Keep blur on background only, add static/seeded grain, a restrained lighting falloff and crisp original pixel imagery. Expose restrained/expressive amount controls without requiring duplicate outputs. Describe raster image plus vector outlines as a hybrid asset.
