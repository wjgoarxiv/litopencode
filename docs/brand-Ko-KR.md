## 표지

README 표지는 반복 재생되는 WebP입니다. 일곱 로봇이 차례로 켜지고 LitOpenCode 로봇이 깨어납니다. 움직임 줄이기를 설정한 사람에게는 [불이 켜진 마지막 장면](./assets/cover-motion-still.webp)이 정지 화면으로 보입니다. 편집할 수 있는 가벼운 벡터 표지는 [docs/assets/cover.svg](./assets/cover.svg)에 있습니다. 이 저장소에만 있고 npm 패키지에는 들어가지 않습니다.

링크 미리 보기 카드에 쓰는 1280×640 [소셜 미리 보기 이미지](./assets/social-preview.png)도 같은 표지로 만들었습니다. 이 파일도 npm 패키지에는 넣지 않습니다.

<p align="center"><img src="./assets/readme/ascii-readme.svg" width="480" alt="LIT ASCII B 마크" /></p>

## LITFAMILY

![LitClaude, LitHermes, LitCodex, LitOpenCode, LitGrok, LitMuse, LitGravity를 표현한 일곱 중장갑 머신](./assets/readme/litfamily-machines.png)

LitClaude · LitHermes · LitCodex · LitOpenCode · LitGrok · LitMuse · LitGravity.
일곱 중장갑 머신으로 일곱 제품을 표현한 일러스트입니다. 각 제품은 자기 도구 안에서 독립적으로 동작합니다. 제품별 설치 명령은 [LitFamily 허브](https://github.com/wjgoarxiv/litfamily)에 있습니다.
